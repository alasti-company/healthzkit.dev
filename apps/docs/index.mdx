Healthzkit is a small, framework-agnostic library for Kubernetes-style **liveness** and **readiness** probes in Node.js.

You define checks as adapters that return `ok`, `degraded`, or `fail`. Healthzkit runs the relevant checks in parallel, rolls up an overall status, maps that to an HTTP response, and can schedule slow checks in the background so probes read cached results.

## What you get

  <Card title="Liveness and readiness" icon="heart-pulse">

## Install

The package is ESM-only. Published packages declare Node.js 22.12+.

<CodeGroup>
```bash pnpm
pnpm add healthzkit
```

```bash npm
npm install healthzkit
```

</CodeGroup>
