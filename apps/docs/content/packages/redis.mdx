The **`@healthzkit/redis`** package provides three **`HealthAdapter`** factories for different Redis stacks: **`ioredis`**, the official **`redis`** Node client, and **`@upstash/redis`**. Each runs a **`PING`** (or a custom command you configure), records **`metadata.latencyMs`**, and returns **`status: "ok"`** or **`status: "fail"`** with an **`error`** on failure.

Peer dependencies **`ioredis`**, **`redis`**, and **`@upstash/redis`** are **optional** — install only the client you use.

## Install

**ioredis:**

```bash
npm install healthzkit @healthzkit/redis ioredis
```

**node-redis (`redis`):**

```bash
npm install healthzkit @healthzkit/redis redis
```

**Upstash:**

```bash
npm install healthzkit @healthzkit/redis @upstash/redis
```

## `ioredisAdapter`

```ts
import { createHealthKit } from "healthzkit";
import { ioredisAdapter } from "@healthzkit/redis";
import Redis from "ioredis";

const redis = new Redis(process.env.REDIS_URL);

const kit = createHealthKit({
  checks: [
    {
      name: "redis",
      type: ["readiness"],
      adapter: ioredisAdapter({ client: redis }),
    },
  ],
});
```

### Options

| Option                 | Description                                                                                                                        |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **`client`**           | Existing **`Redis`** instance.                                                                                                     |
| **`connectionString`** | Creates an internal **`Redis`** with **`maxRetriesPerRequest: 1`**, **`enableReadyCheck: false`**, merged with **`redisOptions`**. |
| **`redisOptions`**     | Only with **`connectionString`** — extra **`ioredis`** options.                                                                    |
| **`command`**          | String passed to **`client.call(...)`**. Default **`"PING"`**.                                                                     |
| **`metadata`**         | Optional **`async (client) => Record<string, unknown>`**.                                                                          |

## `nodeRedisAdapter`

For **`redis`** package clients (**`createClient`**, **`sendCommand`**).

```ts
import { createHealthKit } from "healthzkit";
import { nodeRedisAdapter } from "@healthzkit/redis";
import { createClient } from "redis";

const client = createClient({ url: process.env.REDIS_URL });
await client.connect();

const kit = createHealthKit({
  checks: [
    {
      name: "redis",
      type: ["readiness"],
      adapter: nodeRedisAdapter({ client }),
    },
  ],
});
```

### Options

| Option                 | Description                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`client`**           | Client with **`sendCommand`**, **`isOpen`**, and **`connect`**. If **`isOpen`** is false, the adapter **`await`s `connect()`** before the check. |
| **`connectionString`** | Lazily **`createClient({ url, ...redisOptions })`**, **`connect()`** once, reuse for later checks.                                               |
| **`redisOptions`**     | Only with **`connectionString`** — merged into **`createClient`**.                                                                               |
| **`command`**          | Default **`"PING"`**. Split on spaces for **`sendCommand`**, e.g. **`"GET mykey"`** → **`["GET", "mykey"]`**.                                    |
| **`metadata`**         | Optional; receives the same client type.                                                                                                         |

## `upstashAdapter`

For serverless / HTTP Redis (**`@upstash/redis`**).

```ts
import { createHealthKit } from "healthzkit";
import { upstashAdapter } from "@healthzkit/redis";
import { Redis } from "@upstash/redis";

const redis = new Redis({
  url: process.env.UPSTASH_REDIS_REST_URL!,
  token: process.env.UPSTASH_REDIS_REST_TOKEN!,
});

const kit = createHealthKit({
  checks: [
    {
      name: "redis",
      type: ["readiness"],
      adapter: upstashAdapter({ client: redis }),
    },
  ],
});
```

### Options

| Option                  | Description                                                                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **`client`**            | Existing Upstash **`Redis`** instance.                                                                                                |
| **`url`** / **`token`** | If both set, lazily constructs **`new Redis({ url, token })`**.                                                                       |
| **`command`**           | Default **`"PING"`** uses the client’s **`ping()`**. Any other string is split into **`[command, ...args]`** and sent via **`exec`**. |
| **`metadata`**          | Optional; receives the Upstash client.                                                                                                |

## Using with scheduling

Redis checks are a good fit for **`schedule: { intervalMs }`** so readiness probes stay fast while the adapter runs **`PING`** (or your command) in the background. See [Scheduling](/healthzkit#scheduling).
